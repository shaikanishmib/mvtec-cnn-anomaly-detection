# SuperSimpleNet preregistered development and pilot policy

Recorded before GPU experiments. Official test images/masks are forbidden until a complete policy is frozen. Calibration normals are reserved and unavailable for development selection. Existing seed-2026 manifests remain authoritative.

Sources: [ICPR paper, arXiv v2](https://arxiv.org/html/2408.03143v2) and [official implementation pinned at 98ab4d5fbdcdef528fafbc42e4b5ee15f08f5a7d](https://github.com/blaz-r/SuperSimpleNet/tree/98ab4d5fbdcdef528fafbc42e4b5ee15f08f5a7d). MIT attribution is retained in `docs/third_party/SuperSimpleNet_LICENSE.txt`. The current official default includes a later JIMS change: this project targets the original adapted-classifier ICPR path (`adapt_cls_feat=True`), unsupervised stop-gradient setting.

Reference components: ImageNet V1 WideResNet50-2 layers 2/3, upscale both to 64x64 before concatenation and 3x3 average pooling; 1536-channel adapter; segmentation hidden width 1024; detection width 128, pooled features and detached segmentation logits; independent Perlin-masked Gaussian noise on both duplicated feature batches, half clean; Gaussian standard deviation .015, mask threshold .2; separately balanced margin .5 plus focal segmentation and focal detection (gamma 4). AdamW parameter groups follow the official implementation; milestone fractions .8/.9 and multiplier .4. Raw logits, fixed Gaussian sigma4 interpolation, no test-derived score normalization.

Intentional differences: whole-image 256 resizing and established manifests; normal-only fitting; three rather than five final seeds; reduced fixed 40 epochs rather than the paper's 300; batch sizes 4/8 rather than 32; gradient norm clipping at 10 as a numerical guard; independently seeded Perlin implementation, not bit-identical RNG; no real-anomaly mask dilation in this normal-only setting. The Lite candidate uses ResNet18 V1 and widths 384/256/32. Neither reduced-budget model is claimed to reproduce paper numbers.

Pilot: CPU shape/target/gradient/checkpoint checks, 12 reference-width GPU steps on four fitting-normal bottle images, then 20 Lite epochs on 32 fitting normals with eight disjoint fitting-normal synthetic probe sources and 16 predefined development normals. Pilot probe noise is a synthetic diagnostic, never evidence of real defect quality. Measure shapes, loss, gradients, runtime, allocated/reserved VRAM, process RSS and exact checkpoint replay. Preserve failures.

Bounded development subset, selected before official test access: bottle and cable (objects), carpet and tile (textures). Inner fitting split uses existing deterministic utility. At most five configurations: reference; Lite .015; Lite .05; Lite .015 frozen adapter; Lite .015 focal-only segmentation. Fixed 40 epochs, seed2026, final checkpoint, development every10 epochs. Reference is eligible for broad study only if measured 45-fit training projection is at most 90 minutes and allocated VRAM below6GiB. No automatic epoch extension or extra search rounds. Proxy generation seeds9901/9902 are fixed on held-out fitting normals; normal development data stays unmodified.

Compare learned detection head, max map and top1% map aggregation at the last epoch. Mean four-category objective is `(synthetic image AUROC + synthetic pixel AP)/2 - .25*max(0, synthetic clean-image FPR-.05)`. Image threshold for this diagnostic is normal-development q95; this is not final calibration. Select highest mean objective; within .005 prefer lower measured training time, then fewer parameters. Diagnose chance performance or nonfinite loss before increasing scale. Synthetic proxy selection cannot establish synthetic-to-real generalization.

Before all-category fitting, publish actual pilot/development measurements and projected workload, freeze source/configuration/weights/aggregation/epochs, and verify correctness. Final seeds2026/2027/2028 are permitted only if the measured workload fits the budget. Fit all category models before official test evaluation; do not retrain after seeing final results. Separate image q95 and pixel q99.5 higher-quantile normal calibration with strict `>` decisions match prior conventions; report sample size, test FPR and uncertainty. No retrospective test threshold adjustment.

## Prospective diagnostic clarification before candidate comparisons

The two completed tiny pilots use their own training-noise magnitude for within-trial diagnostics. They are not directly comparable quality benchmarks. For configuration selection, evaluate **every final development checkpoint on identical held-out fitting sources and fixed .05 proxy noise**, with the same seed9901/9902 masks/noise. Training-curve diagnostics may retain the training magnitude and are labeled accordingly. This prevents a candidate from benefiting merely because its evaluation perturbations are easier. Record a separate common-proxy evaluation for every candidate/category; select solely from those evaluations. This clarification precedes completed four-category candidate comparisons and any official test access.

The measured initial Lite projection is101 minutes for three-seed training alone. Use development timing to decide final seed coverage prospectively: three seeds only if projected training is at most90 minutes; otherwise one fixed seed2026. Reduced seed coverage must be explicit in the report, and paired image bootstrap must not be described as training-seed uncertainty. Do not reduce the fixed epoch count retrospectively to fit more seeds.
